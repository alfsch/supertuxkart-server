# How the logo was made

`logo-original.jpg` was generated on 2026-11-23 with Microsoft's Bing Image Creator, from this prompt:

```
Flat vector logo icon for a software project: a cute cartoon penguin racing in a small
go-kart, riding on top of an orange shipping container with a checkered racing flag
stripe. Bold clean outlines, simple shapes, vibrant colors (orange, blue, white),
minimal flat design, centered, plain solid dark navy background, no text, no letters,
no watermark, square composition
```

`logo.png` is the same image cropped to the subject (656×536); the generator's "Made with AI" badge in the top-right corner
is outside the crop.

The prompt names neither SuperTuxKart nor Tux, so the logo uses no artwork of the SuperTuxKart project. No license is claimed
for it: whether an AI-generated image can be copyrighted is unclear, and Microsoft's terms for the Image Creator apply. This
repository is not made, endorsed or supported by the SuperTuxKart project.

`social-preview.png` (1280×640) is `logo.png` on the same background with the name and a caption set beside it. It is the image
for the repository's social preview (Settings, General, Social preview), which GitHub only lets you upload in its web interface.
